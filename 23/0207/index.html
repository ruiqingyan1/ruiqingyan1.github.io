5、继承与派生

继承用来表达类之间的“是一种”关系。

这里 Mammal 是基类，Dog 是派生类。可以说：Dog 是一种 Mammal。

概念 说明
基类 被继承的类，也叫父类
派生类 通过继承得到的新类，也叫子类
继承 派生类获得基类成员，并可扩展新成员
派生 从已有类生成新类的过程

复盘时先问一句：这个关系是不是稳定的 is-a？如果只是“拥有一个”，通常更适合组合，比如 Car 有一个 Engine，不应该写成 class Car : public Engine。

6、三种继承方式

继承方式会影响基类成员在派生类中的访问属性。

基类成员访问属性 public 继承后 protected 继承后 private 继承后
public public protected private
protected protected protected private
private 不可直接访问 不可直接访问 不可直接访问

6.1 公有继承

公有继承最常用，用来表达真正的 is-a。

公有继承保持基类公有接口仍然对外可见。

6.2 保护继承

保护继承会把基类的 public 和 protected 成员都变成派生类中的 protected 成员，类外不能直接访问。

6.3 私有继承

私有继承会把基类的 public 和 protected 成员都变成派生类中的 private 成员。

初学阶段大多数继承都应优先考虑 public。如果发现自己需要 private 继承，先想想是不是组合更清楚。

10、虚基类

多继承可能产生菱形结构。

如果 B 和 C 都普通继承自 A，那么 D 对象中会有两份 A 子对象。虚基类让共同基类只保留一份。

这样 D 里只有一份共享的 A 子对象。

不使用虚基类 使用虚基类
共同基类子对象可能有多份 共同基类子对象只有一份
访问同名成员容易二义性 解决重复继承带来的二义性
构造路径更直接 最派生类负责虚基类初始化
