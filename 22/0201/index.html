5、程序设计语言的发展

计算机程序设计语言的发展，本质上是不断提高抽象层次的过程：从直接控制硬件，到用接近自然语言和问题领域的方式描述程序。

阶段 表达方式 特点 局限
机器语言 0 和 1 组成的指令 计算机可以直接执行，效率高 难写、难读、依赖硬件
汇编语言 助记符表示机器指令 比机器语言可读，仍接近硬件 可移植性差，开发复杂
高级语言 接近数学表达和自然语言 可读性、可维护性、可移植性更好 需要编译或解释
面向对象语言 用对象、类和消息组织程序 更适合表达复杂系统中的实体关系 需要先理解抽象和建模

可以这样记：机器语言面向机器，汇编语言面向指令，高级语言面向算法，面向对象语言面向问题中的对象。

C++ 是在 C 语言基础上发展出来的语言。它一方面保留了 C 语言接近底层、效率高、可控制性强的特点，另一方面引入了类、对象、继承、多态等机制，让大型程序可以更好地组织。

6.1 对象

对象是系统中用来描述客观事物的基本单位。一个对象通常包含两部分：

属性 对象的静态特征 学生的姓名、学号、成绩
行为 对象可以执行的操作 选课、考试、查询成绩

6.2 类

类是对同一类对象共同特征的抽象。对象是具体的，类是抽象出来的模板。

概念 解释
类 抽象模板，规定一类对象有哪些属性和行为
对象 类的实例，是程序运行中真实存在的实体
实例化 根据类创建对象的过程

Student 是类，alice 和 bob 是两个对象。

6.3 封装

封装就是把对象的属性和行为组织在一起，并隐藏对象内部实现细节，只向外提供必要接口。

value 被放在 private 中，外部不能随意修改，只能通过 increase() 和 getValue() 访问。

封装不是把代码藏起来这么简单。 它真正的作用是控制访问边界，让对象内部状态不被外部随便破坏。

6.4 继承

继承用来表达类与类之间的“是一种”关系。子类可以复用父类已有的数据和行为，也可以扩展自己的特性。

Student 是一种 Person，所以学生拥有人的公共行为，同时又有自己的学习行为。

6.5 多态

多态表示同一个接口在不同对象上表现出不同的行为。

同样调用 area()，圆形和矩形会使用各自的面积计算方式。

7、结构化程序设计与面向对象的对比

结构化程序设计强调自顶向下、逐步求精、模块化分解。它适合把问题拆成函数和流程。

方法 组织中心 优点 局限
结构化程序设计 函数和过程 思路清晰，适合算法和流程控制 数据和操作分离，复杂系统维护成本高
面向对象程序设计 对象和类 更贴近问题领域，便于封装和复用 需要先建立合理抽象，设计不当会变复杂

不要把面向对象理解成“把函数放进类里”。 面向对象关注的是对象之间的关系、责任边界和可维护性。

9、信息的表示与存储

9.1 计算机内部的信息分类

计算机内部的信息大致可以分成两类：

大类 子类 说明
控制信息 指令、控制字 告诉计算机“做什么、怎么做”
数据信息 数值信息、非数值信息 被处理的对象，如整数、字符、图像、声音

9.2 二进制

二进制是以 2 为基数的计数方式，只使用 0 和 1 两个符号，遵循“逢二进一”。

选择二进制的原因 说明
易于物理实现 高低电平、通断状态都能对应 0/1
运算规则简单 加法、乘法、逻辑运算规则更统一
可靠性高 两种状态容易区分，抗干扰能力较强
通用性强 数值、字符、图像、声音都能编码为二进制

缺点也很明显：表示同一个数时，二进制通常比十进制更长。

9.3 进制转换

转换 方法
十进制整数转二进制 除 2 取余，逆序排列
二进制转十进制 按位权展开求和
二进制转十六进制 从右向左每 4 位分一组
十六进制转二进制 每 1 位十六进制展开成 4 位二进制

10、程序开发的基本概念

步骤 内容 常见文件

12、课后习题答案

以下答案已按复盘笔记重新整理，不再直接堆放 PDF 抽取文字。重点题目补了计算过程和易错提醒。

1-1 简述计算机程序设计语言的发展历程

程序设计语言大致经历了下面几个阶段：

阶段 说明
机器语言 用二进制机器指令编程，计算机可直接执行
汇编语言 用助记符代替机器指令，需要汇编后执行
高级语言 用更接近数学和自然语言的方式编写程序
面向对象语言 用对象、类、封装、继承、多态组织程序

答案要点：语言发展的核心是抽象层次提高，程序员逐渐从机器细节中解放出来。 C++ 属于高级语言，也是一种支持面向对象程序设计的语言。

1-2 面向对象的编程语言有哪些特点

面向对象编程语言的主要特点：

特点 说明
对象建模 直接用对象描述现实世界或问题领域中的实体
类与抽象 抽取同类对象的共同属性和行为，形成类
封装 把数据和操作数据的方法放在一起，并隐藏内部细节
继承 子类复用和扩展父类已有功能
多态 同一接口在不同对象上表现出不同实现
代码复用 通过类库、继承、模板等方式减少重复开发

总结：面向对象语言更适合描述复杂系统，能提高程序的可维护性、可扩展性和可复用性。

1-3 什么是结构化程序设计方法？优点和缺点是什么

结构化程序设计是一种面向过程的程序设计方法，强调：

优点：

优点 说明
思路清晰 适合把复杂任务拆成多个子任务
易于实现 每个模块可以独立设计和测试
易于维护 功能模块边界较清楚
适合算法流程 对计算过程明确的问题很有效

缺点：

缺点 说明
数据和操作分离 数据结构变化时，相关函数往往都要修改
复用能力较弱 很多逻辑依赖具体流程，难以抽成稳定对象
不适合复杂交互系统 事件驱动、图形界面和大型软件更难用纯流程描述

一句话概括：结构化方法适合过程清晰的算法问题，但在大型复杂系统中，单纯依靠过程分解会越来越难维护。

1-4 什么是对象？什么是面向对象方法？这种方法有哪些特点

对象是系统中描述客观事物的基本单位，由属性和行为组成。

面向对象方法是把数据和操作数据的方法封装成对象，再通过对象之间的消息交互完成系统功能的方法。

主要特点：

特点 解释
抽象 从具体对象中抽取共同特征，形成类
封装 把属性和行为组织成一个整体
继承 子类可以复用父类已有内容
多态 同一操作可以在不同对象中有不同表现
贴近现实 程序结构更接近问题领域本身

1-5 什么叫做封装

封装是把对象的属性和行为结合成一个独立单位，并尽量隐藏对象内部细节，只保留必要接口。

例如：

balance 不能被外部随意修改，只能通过 deposit()、withdraw()、getBalance() 访问。这样可以保护对象内部状态。

答案要点：封装 = 数据 + 操作 + 访问控制。

1-6 面向对象的软件工程包括哪些主要内容

面向对象软件工程包括：

内容 英文缩写 说明
面向对象分析 OOA 分析系统中有哪些对象和职责
面向对象设计 OOD 设计类、关系、接口和模块
面向对象编程 OOP 用语言实现类和对象
面向对象测试 OOT 测试对象、类和对象交互
面向对象维护 OOSM 对已有系统进行修改、扩展和维护

1-7 简述计算机内部的信息可分为几类

计算机内部信息可分为两大类：

大类 小类 作用
控制信息 指令、控制字 控制计算机执行操作
数据信息 数值信息、非数值信息 表示程序要处理的数据

数值信息包括整数、实数等；非数值信息包括字符、图像、声音、逻辑值等。

1-8 什么叫二进制？使用二进制有什么优点和缺点

二进制是基数为 2 的计数方法，只使用 0 和 1 两个符号，每一位的权值是 2 的幂。

优点：

优点 说明
易于物理实现 高低电平可以直接表示 0/1
运算简单 规则少，适合逻辑电路
可靠性高 两种状态容易区分
通用性强 各类信息都能编码成二进制

缺点：

缺点 说明
位数较长 同一个数用二进制表示时通常更长
人类阅读不直观 所以常用十六进制压缩表示

补码 与原码相同 反码末位加 1 加减法可以统一处理，计算机常用
