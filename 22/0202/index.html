5、C++ 简单程序结构

一个最小的现代 C++ 程序可以写成：

组成 作用
#include <iostream> 引入标准输入输出流库
int main() 程序入口，返回 int 表示程序结束状态
{ ... } 函数体
std::cout 标准输出流
return 0; 程序正常结束

教材中的旧写法 #include <iostream.h>、void main() 在早期编译器中常见，但现代 C++ 推荐写成#include <iostream> 和 int main()。

首字符 必须是字母或下划线
后续字符 可以是字母、数字或下划线
不能使用 关键字、空格、@、- 等特殊符号

6.2 常量与变量

概念 含义 例子
常量 程序运行期间值不改变 const double PI = 3.1416;
变量 程序运行期间值可以改变 int score = 85;

优先使用 const 定义常量，而不是宏 #define。const 有类型，编译器可以检查错误，调试时也更清楚。

7、基本数据类型

类型 常见名称 用途
整型 short、int、long、long long 表示整数
字符型 char 表示字符或小整数
浮点型 float、double、long double 表示小数
布尔型 bool 表示 true 或 false
空类型 void 表示无返回值或无类型

不同平台上类型字节数可能不同，学习时用 sizeof 实测，不要死背某一个编译器的结果。

12、作用域与存储类型

概念 含义
作用域 标识符在程序中有效的区域
局部变量 在函数或语句块内部定义，只在局部有效
全局变量 在函数外定义，具有文件作用域

变量常见存储类型：

存储类型 说明
auto 普通局部变量，通常位于栈上，现代 C++ 中 auto 也用于类型推断
register 建议变量放寄存器，现代 C++ 中基本不再手动使用
extern 声明外部变量或函数
static 静态存储期，程序运行期间一直存在

全局变量虽然方便，但容易让程序状态变乱。初学时能用局部变量解决，就尽量不要依赖全局变量。

2-1 C++ 语言有哪些主要特点和优点

C++ 的主要特点：

特点 说明
兼容 C 保留 C 的高效、灵活、接近底层等特点
支持面向对象 提供类、对象、封装、继承、多态
类型检查更强 相比 C，编译器能检查出更多类型错误
支持泛型编程 模板和 STL 支持复用算法与容器
可移植性较好 标准 C++ 程序可以在不同平台编译

一句话：C++ 既能接近底层，又能做抽象建模。

2-2 判断合法标识符

test2 合法 后续字符可以有数字
3in1 不合法 不能以数字开头
@mail 不合法 不能含 @
A_B_C_D 合法 字母和下划线组成

2-14 if (x = 3) 与 if (x == 3) 的区别

写法 含义
if (x = 3) 把 3 赋给 x，表达式值为 3，条件为真
if (x == 3) 判断 x 是否等于 3

这是 C++ 初学最常见错误之一：判断相等必须写 ==，不要写成 =。

2-15 作用域、局部变量、全局变量

概念 说明
作用域 标识符在程序正文中有效的范围
局部变量 在函数或代码块内部定义，只在该范围内有效
全局变量 在函数外部定义，从定义处到文件结束范围内有效

全局变量可以被多个函数访问，但应谨慎使用。
