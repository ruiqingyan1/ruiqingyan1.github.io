概念—机器语言 & 汇编语言

AMD、Intel 等不同 CPU 拥有不同的 指令集（Instruction Set），CPU 最终只能执行 机器语言。

机器语言：CPU 唯一能够直接识别和执行的语言，由 二进制（0/1） 组成。

汇编语言：使用 助记符（ADD、SUB 等） 代替机器语言（二进制指令），提高程序可读性。

机器语言 ⇄ 汇编语言：一一对应（1 : 1），汇编语言需经过 汇编器（Assembler） 转换后才能被 CPU 执行。

执行流程：汇编语言（ADD） → 汇编器（Assembler） → 机器语言（011100…） → CPU

概念—汇编语言 & 高级语言

高级语言（如 C 语言）更接近人的思维，易于编写和维护。

编译器（Compiler） 负责将高级语言翻译成 汇编语言 或 机器语言。

一条高级语言通常会编译成多条汇编指令。

执行流程：高级语言 → 编译器（Compiler） → 汇编语言 → 汇编器（Assembler） → 机器语言 → CPU

对应关系：

一条高级语言 ≠ 一条汇编指令，而是通常对应多条汇编指令。
