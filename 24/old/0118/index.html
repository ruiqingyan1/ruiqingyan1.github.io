0118、安全开发篇（三）：函数增强与封装入门

发表于2026-07-07|更新于2026-07-07|网络安全Ferry学院安全开发
|字数总计:1.1k|阅读时长:4分钟|阅读量:

返回：C++ 面向对象基础目录 · 安全开发总目录

这一章一半是函数增强，一半是封装入门。函数增强让 C++ 接口更灵活；封装则把数据和行为放到一起，为后面的对象模型、构造析构和多态打基础。

3.2 默认参数

默认参数让调用者可以省略常用值。

复盘重点：默认参数通常写在声明处，不要在声明和定义里重复写不同默认值。

3.3 函数重载

函数重载允许同名函数根据参数列表区分。

能否重载 原因
参数个数不同 可以
参数类型不同 可以
参数顺序不同 可以
只有返回值不同 不可以

3.4 内联函数

inline 表达希望编译器把函数体展开，减少调用开销。它不是强制命令，最终由编译器决定。

小函数可以考虑内联，复杂函数不要为了“快”盲目内联。

3.5 函数模板

函数模板让同一套逻辑适配多种类型。

模板不是运行时万能函数，而是编译期按类型生成对应版本。

3.6 递归函数

递归函数要有出口，否则会无限调用直到栈耗尽。

复盘重点：递归深度、出口条件、重复计算和栈空间。

3.7 回调函数

回调就是“把函数作为参数传进去，之后由别人调用”。它适合事件处理、排序规则、插件式逻辑。

现代 C++ 里还会用 lambda、std::function 表示回调。

3.8 面向对象编程

面向对象不是把所有东西都写成类，而是把“数据”和“操作数据的行为”放在一个稳定边界里。

概念 复盘重点
封装 对外暴露必要接口，隐藏内部实现
继承 复用和扩展已有类型
多态 通过基类接口调用派生类行为

3.9 类与结构体

C++ 中 class 和 struct 的主要默认区别是访问权限：class 默认 private，struct 默认 public。

4.0 类的声明与定义

类可以只声明接口，把实现放到 .cpp 文件。项目里这样更清晰。

4.1 类的访问权限

权限 含义
public 类外可访问
protected 类内和派生类可访问
private 只有类内可访问

访问权限不是安全边界，但它能帮助项目保持封装。

4.2 类的作用域

类成员在类作用域内。类外定义成员函数要带 ClassName::。

4.3 类的对象模型

对象通常只保存成员变量；普通成员函数在代码区，调用时会隐式传入 this 指针。逆向 C++ 程序时，this、成员偏移、虚表指针都很关键。

内容 在哪里
成员变量 对象内存中
普通成员函数 代码区
this 指针 调用成员函数时隐式传入
静态成员 不属于单个对象
