0100、Ferry 学院安全开发：总目录

1、学习定位

Ferry 学院安全开发这一条线先补 C/C++ 与 Windows 平台开发基础。它不是单纯刷语法，而是为后面的逆向、调试、内存分析、漏洞理解和安全工具开发打底。

2、分篇目录

编号 分篇 主要内容 笔记入口
01 安全开发篇（一）：C/C++ 基础入门 C 语言基础、数据类型、控制流、数组、字符串、结构体、指针、函数 0101
02 安全开发篇（二）：C/C++ 进阶提升 函数栈、调用约定、指针进阶、文件读写、内存管理、项目练习 0110
03 安全开发篇（三）：C++ 面向对象基础 命名空间、引用、new/delete、类与对象、构造析构、继承、多态、项目设计 0115
04 安全开发篇（四）：C++ 泛型编程详解 函数模板、类模板、STL、string、vector、deque、list、set、map、异常处理 0122

4、复盘重点

方向 复盘重点
语法基础 变量、类型、控制流、函数、数组、结构体和指针要能写代码验证
内存理解 指针、引用、栈、堆、对象布局和生命周期要能画图说明
工程表达 每个小项目记录需求、结构、关键代码和调试过程
安全连接 重点关注越界、野指针、内存保护、文件处理和输入输出边界

5、后续整理模板

每个章节页按“学习目标 → 关键词 → 代码实验 → 安全联系 → 问题复盘”整理。后续如果继续学习视频细节，再把调试截图、实验记录和个人踩坑补到对应编号里。
