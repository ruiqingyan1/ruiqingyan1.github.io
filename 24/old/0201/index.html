0201、Windows 零基础逆向教程（一）：入门篇

发表于2026-07-06|更新于2026-07-07|网络安全Windows逆向
|字数总计:998|阅读时长:3分钟|阅读量:

返回：Windows 逆向总目录 · 网络安全学习主页

这一篇是 Windows 逆向的入门主线，内容很长，不能全部塞进一篇文章里。这里按“环境与数据 → 寄存器与标志位 → 内存与汇编框架 → 指令与堆栈 → 控制流逆向 → 数据结构逆向 → C++ 对象逆向 → MASM → x64 → 调试器项目”的节奏拆成章节页。

1、学习定位

入门篇要建立三条线：

线索 目标
汇编线 能看懂常见指令、寄存器、标志位、堆栈和调用过程
逆向线 能把 C/C++ 代码和反汇编结构互相对应
调试线 能使用 DBG/IDA/Visual Studio 观察程序运行、断点、异常和模块信息

对我来说，这一篇不是为了“记住所有指令”，而是为了能在调试器里看懂程序正在做什么。

3、整理原则

逆向笔记只记录合法学习、授权分析和防护理解。涉及缓冲区溢出、堆栈逃逸、断点、调试器等内容时，重点放在原理复盘、调试观察和安全边界，不整理未授权攻击流程。

4、复盘重点

方向 复盘重点
二进制数据 进制、位宽、截断、补码、端序和编码
CPU 状态 寄存器、EFLAGS、EIP/RIP、栈指针和基址指针
汇编指令 数据传送、算术、位运算、比较跳转、字符串指令
栈与函数 参数、返回地址、栈帧、调用约定和返回值
控制结构 if/switch/loop 在汇编中的形态
数据结构 数组、指针、结构体、对象、虚表的内存布局
工具使用 Visual Studio、DBG、IDA 的断点、单步、交叉引用和回溯
