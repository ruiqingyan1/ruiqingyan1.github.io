Visual Studio下载

项目 说明
使用 IDE Visual Studio 2019
安装包 https://ruiqingyan.com/downloads/tools/Visual_studio_2019.exe
关键工作负载 使用 C++ 的桌面开发
建议权限 安装时以管理员身份启动

安装流程

步骤 示例图
以管理员身份启动
等待安装包下载并释放资源
选择工作负荷
设置安装目录
等待安装完成
登录账号
启动 Visual Studio

汇编环境

1、创建工程项目（空项目）

2、右键工程项目 –> 生成依赖项 –> 生成自定义 –> masm

3、右键源文件 –> 添加 –> 新建项 –> Main.asm（任意类型修改文件后缀即可）

4、扩展 –> 管理扩展 –> 联机 –> ASMDUDE（颜色）–> 重启 Visual Studio 点击 modify 安装扩展

ASMDUDE 实际展示的时候颜色有问题，我用的是 AsmHighlighter

主题推荐插件 Doki-theme

5、右键工程项目 –> 属性 –> 链接器（高级）–> 入口点（main）

下述代码依次是x32、x64 代码 （x86别名x32，x86_64别名x64）
