000、网络安全学习主线：Ferry 学院优先与 R0 防御专项

发表于2026-08-24|更新于2026-09-12|网络安全
|字数总计:1.9k|阅读时长:6分钟|阅读量:

本页作为 网络安全学习 的总目录。近期目标先很明确：先把 Ferry 学院七部分完整学完，再进入 Windows 逆向、R0 内核安全防御、Rootkit 检测与取证报告模板等专项。

1、当前学习位置

本科课程部分主要放在 本科课程：2022-2023 专业基础，时间上大致对应 2022~2023：只保留 408、数学一和离散数学等重点科目。

2024 年的 AI 内容单独放在 人工智能，考研复盘放在 考研相关。从 2025 年 开始，学习重心转向网络安全：先学 Ferry 学院七部分，再把重心落到 Windows 逆向、安全开发和底层程序分析上。

我个人更倾向于 Windows 逆向。所以网络安全目录不是泛泛铺开 Web、渗透、应急、红队所有方向，而是围绕“C/C++ 安全开发 → Windows 程序基础 → 汇编与调试 → PE/进程/内存 → 逆向分析 → R0 内核安全防御 → 检测取证报告”这条线推进。

涉及 Rootkit、R0、远程取证的内容，只按合法防御研究来整理：记录机制、遥测、检测、取证和报告，不整理隐藏驻留、绕过检测、未授权远控、凭据提取、日志清除等实现步骤。

2、三个月目标与优先级

三个月目标定位成：网络安全完整基础闭环 + Windows R0 防御专项 + 一个可用于复试展示的 AI 安全项目雏形。

学习顺序只排两层：

  1. 先完成 Ferry 学院七部分：前四部分安全开发，后三部分 Windows 逆向。
  2. 再学习其他专项：R0Guard、Rootkit 检测、内存取证、AI 告警解释、合法 CTF 练习和复试材料整理。
优先级 内容 目标 入口
1 Ferry 学院七部分 先把课程主线学完整，补齐 C/C++、Windows 逆向和安全开发底座 0100 · 0200
2 三个月路线 把每周学习重点、产出和检查点固定下来 9000
3 R0Guard 防御专项 学习 R0 内核安全遥测、检测响应和只读取证系统设计 9001
4 Rootkit 检测/取证模板 形成可复用报告结构，后续所有样本和实验都按模板沉淀 9002

2024 人工智能、考研复盘 AI 放在 /23/000/，408 与数学一复盘放在 /14/000/
2025 Ferry 学院七部分 网络安全成为主线，前四部分安全开发，后三部分 Windows 逆向

5、Ferry 学院七部分

顺序 学习模块 内容定位 当前状态
1 安全开发篇（一）：C/C++ 基础入门 环境、C 语言基础、控制流、数组、字符串、结构体、指针、函数 0101
2 安全开发篇（二）：C/C++ 进阶提升 指针进阶、内存、文件、编码、项目组织和工程边界 0110
3 安全开发篇（三）：C++ 面向对象基础 类、对象、构造析构、继承、多态、对象模型 0115
4 安全开发篇（四）：C++ 泛型编程详解 模板、STL、容器、迭代器和泛型设计 0122
5 Windows 零基础逆向教程（一）：入门篇 汇编、寄存器、堆栈、调用约定、调试器基础 0201
6 Windows 零基础逆向教程（二）：提升篇 PE 结构、进程、内存、异常、导入导出和加载过程 0202
7 Windows 零基础逆向教程（三）：攻防篇 Hook、注入、反调试、壳、样本分析和检测防护 0203

前四个阶段先建立开发、调试和内存基础；第五到第七阶段再正式进入 Windows 逆向与安全方向的专项内容。

6、已整理笔记

6.1 安全开发篇（一）：C/C++ 基础入门

这一阶段的课程共 81 节，从课程体系、Visual Studio 环境与 C 程序框架起步，依次学习数据、运算、控制流、数组、字符串、结构体、指针与函数。学习重点不只是记住语法，还要能够通过调试、内存观察和反汇编理解代码的实际执行过程。
